# my-tetris

公式ガイドライン準拠の本格テトリスを、Web ブラウザーで手軽に遊ぶためのプロジェクト。

## コンセプト

- **サーバー不要**: `index.html` をブラウザーで開くだけで遊べる（ビルド・インストール不要）。
- **公式仕様準拠**: SRS（Super Rotation System）・7-bag・ホールド・ゴーストピース・ロックダウンなど、現行ガイドラインの主要ルールに沿ったプレイ感。
- **遊び心のあるデザイン**: テトリスらしい雰囲気を活かしつつ、見た目・演出で楽しさを足す。

## 遊び方

`index.html` をダブルクリック（またはブラウザーにドラッグ＆ドロップ）して起動します。
