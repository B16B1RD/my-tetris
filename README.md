# my-tetris

公式ガイドライン準拠の本格テトリスを、Web ブラウザーで手軽に遊ぶためのプロジェクト。

## コンセプト

- **サーバー不要**: `index.html` をブラウザーで開くだけで遊べる（ビルド・インストール不要）。
- **公式仕様準拠**: SRS（Super Rotation System）・7-bag・ホールド・ゴーストピース・ロックダウンなど、現行ガイドラインの主要ルールに沿ったプレイ感。
- **遊び心のあるデザイン**: テトリスらしい雰囲気を活かしつつ、見た目・演出で楽しさを足す。

## 遊び方

`index.html` をダブルクリック（またはブラウザーにドラッグ＆ドロップ）して起動します。サーバーやビルドは不要です。

### 操作方法（デスクトップ・キーボード）

| キー | 操作 |
|------|------|
| ← → | 左右移動（長押しで DAS/ARR リピート） |
| ↓ | ソフトドロップ |
| Space | ハードドロップ |
| X / ↑ | 右回転（CW） |
| Z | 左回転（CCW） |
| C / Shift | ホールド |
| Esc / P | ポーズ |
| Enter / R | スタート・リスタート |
| M | サウンドのミュート切替 |

## 特徴

- **公式仕様準拠**: SRS 壁蹴り（JLSTZ / I 別テーブル）・7-bag・ホールド・ゴースト・ロックダウン（move reset + infinity 制限）・Back-to-Back。
- **スコア/レベル**: シングル〜テトリス加点、ソフト/ハードドロップ加点、10 ライン毎のレベルアップと重力加速。
- **遊び心のある演出**: パステルのキャンディ風ブロック、ライン消去のコンフェッティと「NICE! / TETRIS!!」ポップアップ、レベルアップ演出。
- **効果音**: WebAudio による合成音（外部ファイル不要）。`M` でミュート。
- **ハイスコア**: `localStorage` に自己ベストを保存。
